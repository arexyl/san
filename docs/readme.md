# San

The native image engine for [Hakusan](https://github.com/arexyl/hakusan), written in Zig. San decodes images and manages native resources behind the ABI defined in [hbinds](https://github.com/arexyl/hbinds). It is in early development.

Clone with submodules:

```sh
git clone --recurse-submodules https://github.com/arexyl/san.git
```
